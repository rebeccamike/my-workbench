使用 GitHub 私密 Gist 做多端同步：① 在 GitHub → Settings → Developer settings → Personal access tokens → 生成 classic token（必须是 classic，不是 fine-grained），勾选 gist 权限；② 把 token 填上方，点「新建 Gist」会自动创建私密 Gist 并填好 ID；③ 打开开关即可。数据存在你自己的私密 Gist，仅你可读写，手机和电脑打开同一链接即自动同步。Token 仅填写在本网页，不要发给任何人（包括 AI 助手）。
数据管理 · 本地备份
本工作台是纯前端单文件应用，数据默认仅存于本机浏览器。点击「保存到文件」会生成一个已内嵌你全部数据的新 HTML——把它拷到任意电脑、双击即用，无需联网、无需安装。也可用 JSON 做轻量备份。
如果打开后看不到数据，或本机数据损坏，点「恢复内置备份数据」可强制用回内置的备份内容（即你之前发给我的那份最新数据）。恢复前如有新内容请先「导出 JSON」备份。
